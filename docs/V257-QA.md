## Selective snippet controls

The owner's reported prefix contains skip controls, locale codes and scene navigation. Those strings are present in the baseline SSR HTML before the main narrative. The candidate marks only their short technical text and audio/video pause labels with supported `span[data-nosnippet]`, including the initial server output. Buttons/anchors retain their hrefs, accessible names, visible text, focus and events. No blanket header/nav/main/article exclusion; factual headings, body copy and internal-link context remain eligible.

Existing `.text-button>span` styles enlarge icons and hide them on phones. The text-only wrapper deliberately inherits the button font/color and uses `display:contents`; it therefore preserves the original anonymous flex text instead of accidentally turning a label into a hidden icon. Tests inspect actual text-range geometry on mobile, supported tags, keyboard focus and unchanged primary content.

Reference: [Google's robots/snippet specification](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag). No global nosnippet/max-snippet:0. Google chooses query-dependent snippets; the account's indexed version/current SERP was not verified and an exact future snippet is not promised. `.pe` and language signals are unchanged; no removed Search Console geo-targeting setting is invented.
