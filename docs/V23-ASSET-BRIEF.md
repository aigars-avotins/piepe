# PIE.PE 2.3 — source limits and optional assets

No new AI media or scientific image is generated for 2.3. The supplied masters are preserved byte for byte. The page's existing artistic-image disclosure remains.

## Current mobile direction

The original 1920×1080 Reveal/Awakening pair has a horizontal composition. Cover on a compact 390×664 screen retains approximately 635 source pixels horizontally; a 390×844 screen retains approximately 499. At the selected 60% focal position the bracket fungus stays in view, but much of the forest is necessarily outside the screen. The 1900×988 Understory crop similarly retains about 580/457 source pixels. Position 40% gives priority to the three principal drops. This is an intentional crop, not newly created portrait detail.

If a later owner review requires more surrounding forest in portrait, request a **matched portrait Reveal + Awakening pair**, rather than generating one isolated replacement. Supply frame zero and frame 144 from both current masters, a 390×844 crop overlay, and the current portrait recording. Keep the same tree, bracket tiers, warm left rim light, mist direction, camera vector and exact Reveal-ending/Awakening-opening silhouette. Request native portrait delivery, 24fps and compatible timing; keep titles/hotspots out of the source. Both pair endpoints must be reviewed at actual scale before integration. Do not simply extend, stretch or sharpen the present picture.

Understory and Breathing remain usable in portrait with the selected focal positions. Additional portrait generation is not justified by the current P0 fixes and is not authorized automatically.

## Optional scientific micro-explainer image

The shipped glossary is text only: fruiting body, pores and mycelium/hyphae. It supplements the existing sourced facts and does not infer a species from the artistic forest film.

For a future illustrated version, obtain a licensed, genuine underside macro of a bracket fungus with clearly resolved pore openings, identification/provenance, credited photographer, source URL and permission for web display. Review the example with a mycologist or a reliable species reference: not every bracket-shaped fungus has pores. A second faithful diagram may distinguish the visible fruiting body from hyphae within wood; label it as a diagram and have the anatomy reviewed. Do not present moss droplets or the AI forest fungus as a microscopic pore photograph. No suitable trustworthy image is currently supplied for that use, so the image layer is deferred.

Search Console ownership/index coverage still requires the owner's account. Crawlable LV/EN HTML, canonical/hreflang, sitemap and structured data remain testable locally; passing these checks does not establish actual Google indexing.
