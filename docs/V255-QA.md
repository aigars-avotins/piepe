## 2. Verified gaps and targeted changes

**No crawlability, canonical, hreflang, sitemap or JSON-LD defect was found.** The changes address editorial clarity, not a broken indexation claim:

- Search titles now align with the already visible factual question: LV **“PIE.PE — Kas ir piepe? Dzīvais mežs tuvplānā”**, EN **“PIE.PE — What is a bracket fungus? The living forest”**. Brand and forest identity remain.
- Descriptions introduce the actual subject and offered experience naturally: LV includes `piepes uz kokiem` / `sēņotni`; EN bracket fungi / shelf fungi / mycelium. They describe the existing cinematic forest, field note and wallpapers, without a keyword list or new page.
- The English definition now explains that a bracket fungus is also called a shelf fungus, in the same existing paragraph. No new section or factual claim about a named species. Latvian definition, poetic hero, observation text and other facts are already clear and remain untouched.
- The generated EN field-note appendix receives the same one-sentence clarification; download names, links and behavior are unchanged.
- The base HTML template's LV fallback is synchronized; prerender and client metadata already share translations. Existing OG/Twitter and JSON-LD automatically receive the new title/description without duplicate markup.
- Version markers become2.5.5; no dependency changes.
