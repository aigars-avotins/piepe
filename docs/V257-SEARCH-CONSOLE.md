# PIE.PE 2.5.7 — Search Console pēc apstiprinātas publicēšanas

**Šis ir pirmsprodukcijas kandidāts. Neiesniedz vēl nepublicētās adreses indeksēšanai.** Darbības zemāk prasa īpašnieka Google kontu un attiecas uz laiku pēc atsevišķi apstiprinātas publicēšanas. Codex nav pieslēgts kontam un nav mainījis tā iestatījumus.

1. **Vispirms pārbaudi publicēto laidienu.** Visām 16 jaunajām adresēm no [QA saraksta](V257-QA.md#new-routes) jāatgriež īsts 200 HTML. Abām sākumlapām un abām 2.5.6 zināšanu lapām jāpaliek pieejamām. Pārbaudi arī skaidru 404 nezināmai adresei.
2. **URL Inspection → Test live URL.** Pārbaudi jauno tapešu lapu pāri, piezīmju indeksu un piezīmes 001–006. Salīdzini saņemto HTML, pašas lapas canonical, valodu un Google izvēlēto canonical pēc indeksēšanas. Ja nepieciešams, izmanto Request indexing; nav jāveido atkārtotu pieprasījumu plūsma. Tas negarantē termiņu vai indeksēšanu.
3. **Sitemaps.** Iesniedz vai pārbaudi to pašu `https://pie.pe/sitemap.xml`. Apstiprinātajā 2.5.7 būvējumā ir 20 canonical adreses desmit LV/EN pāros. Nav jāveido jauns sitemap vai jāmaina robots.txt.
4. **Vecā Google fragmenta pārbaude.** Abām sākumlapām salīdzini indeksēto un dzīvo versiju; pēc atkārtotas pārmeklēšanas vēro fragmentus atbilstošiem vaicājumiem. Šaurās `data-nosnippet` atzīmes attiecas uz tehniskām vadīklu etiķetēm, nevis zināšanu saturu. Google pats izvēlas fragmentu; precīzs teksts nav garantēts.
5. **Settings → Search generative AI.** Pārbaudi faktiskā īpašuma Include izvēli vai mantoto izvēli no augstākā līmeņa īpašuma. Neizdomā, ka `Google-Extended` aizstāj Search iekļaušanas iestatījumu. Šajā uzdevumā konta izvēle nav pārbaudīta vai mainīta.
6. **Mērījumi pēc datu uzkrāšanās.** Search performance pārskatā salīdzini lapas, valstis, ierīces un vaicājumus. Generative AI performance pārskatā, kad tas ir pieejams, vēro rādījumus pa lapām un periodiem; nepieņem vaicājumu līmeņa attiecinājumu vai ka rādījums ir klikšķis vai kvalitatīva atsauce. Seko arī Core Web Vitals, ja ir pietiekami lauka dati. Neliels lokāls veiktspējas mērījums tos neaizstāj.

`.pe` domēns paliek nemainīts. Nav jāmeklē noņemtā ģeogrāfiskās mērķauditorijas iestatīšana. Pareiza valoda, hreflang un noderīgs vietēji atbilstošs saturs ir pārbaudāmi signāli, nevis Latvijas pozīciju garantija. Šis laidiens neiesniedz lapas ārējos katalogos, nesūta preses ziņas un nepērk reklāmu vai saites.
