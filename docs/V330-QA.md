## Tests added or intentionally changed

New in `tests/v330.spec.ts`:

- The atlas loupe never requests an owner JPEG; explicit zoom requests exactly the chosen one.
- A first visit preloads and fetches only the opening frame it paints; reduced-motion and returning visits never fetch it; without JavaScript the settled forest is painted by CSS.
- (LV and EN) The Trails menu reaches every page and both languages from a reading page, by keyboard (Escape, outside press) and without JavaScript; the footer is identical on all 22 documents; the home, footer and portal menus share destinations, and Escape closes the menu before the portal.
- (LV and EN) The About page states the idea, lists the ten films in words, and shows no credits until real ones are entered.
- Every route has a unique, length-checked title and description, its own 1200×630 social image, matching dates in structured data and sitemap, Article and BreadcrumbList where expected, ten VideoObjects on the home page and licensed wallpaper ImageObjects.
- Unknown addresses get the designed 404 page with `noindex`; COOP/CORP headers, one CSP hash, every `_headers` line under 2,000 characters, and a complete manifest.
- No page raises a CSP violation or console error; at 390 px the fixed controls are at least 44 px and there is no horizontal scroll.

Changed on purpose (the assertion described something 3.3 was asked to change):

- **Media version.** Seven hard-coded `?v=2.3` expectations now read `mediaVersion` from `src/release.ts`.
- **CSP.** Four tests required a `script-src` hash for every JSON-LD block. They now require exactly one hash (the boot script) and valid JSON in each data block.
- **Image fallback.** The test that served a fake `/images/interactive/atlas-pores.webp` is replaced by one that proves the fallback lands on the real 960 px copy and never requests the missing file. Regular expressions accept AVIF as well as WebP.
- **Portal stills.** `naturalWidth` is density-corrected under `srcset`, so the tests decode the chosen file instead (1672 px threshold; the quiet world must come from `/images/portal/living-*`). Route patterns allow the version query.
- **Atlas lightbox.** One original (2400 px) plus two sized copies, instead of three originals.
- **Fungus invitation.** Keyboard tests tab to the labelled invitation; the hit area must be `tabindex="-1"` and `aria-hidden`.
- **Preload.** The HTML must contain no `/media/` preload and no `<img src>` for the opening frame; the boot script supplies the one preload.
- **Routes.** Twenty-two canonical documents instead of twenty; the sitemap is compared with the generated file and must carry 22 `lastmod` values.
- **Field notes.** The served note is compared with a reviewed snapshot in `tests/fixtures/` instead of a tracked file the build used to rewrite.
- **Preservation.** `tests/preserved.ts` applies one reviewed ledger (`docs/qa/v330/reviewed-sources.json`) to the 2.5.7, 2.5.8, 2.5.8.1, 3.0 and 3.2 baselines. Every other pinned file must still match its original hash. No film, audio file or matched frame is in the ledger's "changed" list.
- **Test infrastructure.** Native AppKit window activation is limited to the WebKit project (it failed every Chromium test on a Mac); `scroll-recording.spec.ts` skips when `https://pie.pe` or Playwright's ffmpeg is unavailable.

No test was deleted.

## Lighthouse

Lighthouse 13.6 in headless Chrome against the local production build served by `scripts/preview-worker.mjs` (real media Worker, built headers, no compression, no CDN). Three runs each; scores listed per run, metrics are medians. Default Lighthouse settings: mobile uses *simulated* throttling (Moto G Power profile, slow 4G, 4× CPU); desktop uses the desktop preset.

| Page | Form | Performance | Accessibility | Best practices | SEO | FCP | LCP | TBT | CLS |
|---|---|---|---|---|---|---:|---:|---:|---:|
| Home `/` | mobile | 100 / 100 / 100 | 100 | 100 | 100 | 1.35 s | 1.35 s | 0 ms | 0 |
| Home `/` | desktop | 100 / 100 / 100 | 100 | 100 | 100 | 0.32 s | 0.32 s | 0 ms | 0 |
| Field note 003 (EN) | mobile | 100 / 99 / 99 | 100 | 100 | 100 | 1.65 s | 1.65 s | 0 ms | 0.022 |
| Field note 003 (EN) | desktop | 99 / 100 / 100 | 100 | 100 | 100 | 0.40 s | 0.40 s | 0 ms | 0.047 |

**Read these numbers with care.** Simulated throttling estimates timings from an unthrottled trace and is kind to a page whose largest element appears late by design. With *real* DevTools throttling (Lighthouse's default slow-4G profile, three runs) the home page scores 63–66: FCP about 3.5 s, **LCP about 12.5 s**, TBT 0, CLS 0.001. The LCP element is the wordmark that is revealed after the six-second opening film; 3.2 measured 18.3 s under its own, slower custom profile, so the two are not directly comparable. The brief's home-page target (LCP under 2.5 s on throttled mobile) is therefore **met only under simulated throttling**; reaching it under real throttling would mean showing the title over the film or shortening the film, which is an owner decision. The home page also transfers about 11 MB in the Lighthouse window because the opening film downloads during load.

Remaining audit notes: render-blocking CSS on reading pages (the shared 85 KB stylesheet), large hero JPEG frames (kept as matched film frames on purpose), back/forward cache blocked only by the local server's `no-store` header, and one label-in-name heuristic on the sound control (below).

## Known limitations

- **Home-page LCP under real throttling** is about 12.5 s (see Lighthouse). By design, not fixed.
- **Lighthouse label-in-name heuristic** still flags the sound control: its visible hint ("The sound shifts as you explore") is counted as label text even though it is `aria-hidden`. The control's label ("Forest sound") is contained in its accessible name ("Enable forest sound"), which is what WCAG 2.5.3 asks.
- **Reading pages load the shared 85 KB application stylesheet**; a reading-only stylesheet would remove about 0.9 s of render-blocking time on simulated mobile. Not attempted in 3.3.
- **The opening hero frames stay JPEG** (660 KB and 396 KB) because they are matched film frames.
- **Credits and contact** on the About page are empty until the owner fills them in.
- **`.assetsignore` from the earlier 3.3 work is removed** because the files it excluded are no longer in `public/`; check the uploaded-asset count on the first Workers Builds deploy.
