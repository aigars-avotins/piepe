## Deliberately not changed

These audit items collide with decisions the existing tests and manifests protect, so they are left for the owner:

- **Quiet portal still** (`/media/01_Start.png`, 2.9 MB PNG, also sent to Save-Data visitors): pinned as the audited original still.
- **`?v=2.3` media cache-buster**: pinned in eight tests, and the media bytes have not changed since 2.3, so changing it would only invalidate caches.
- **JSON-LD CSP hashes**: JSON-LD is a data block and should not need `script-src` hashes, but the tests require them. The new build guard covers the practical risk.
- **Alternate image fallback** (`/images/interactive/<name>.webp` does not exist): an exercised, tested fallback slot; it costs one 404 only when both real sources have already failed.
- **Home-page structured data, `public/_headers`, the Worker, `wrangler.jsonc`**: frozen. HSTS is therefore an owner decision.
- **`public/site.webmanifest`**: frozen by two inventories; an enrichment was tried and reverted.
- **Build writing `public/field-note-*.txt`**: a test compares the served note with the tracked copy.
- **Sitemap `lastmod`, per-route social images, colophon page, navigation or typography redesign, bundle splitting**: not attempted. They need real modification dates, new routes (the suite asserts exactly 20) or design decisions that should be made with the owner looking at the result.
